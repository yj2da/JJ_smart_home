하드웨어 장치 제어

RGB LED 메인 전등

GPIO 25(Red), 26(Green), 27(Blue) 공통 캐소드 LED를 제어합니다.

HD44780 I2C LCD (16x2)

스마트홈 상태 표시 LCD 화면 백라이트를 제어합니다.

피에조 부저 멜로디

GPIO 23 PWM 주파수를 활용한 멜로디 음원을 재생합니다.

SSD1306 OLED 디스플레이

128x64 흑백 OLED 화면에 헬로키티 비트맵 이미지(img/kitty.pbm)를 출력합니다.
